# 展览筹备小组组织图｜信息图分析报告

来源：本仓库原创教学案例，使用虚构数据。

## 示例数据

| 节点 | 上级 |
|---|---|
| 筹备组 | 根节点 |
| 内容组 | 筹备组 |
| 场务组 | 筹备组 |
| 图文审核 | 内容组 |
| 现场布置 | 场务组 |

## 数据结构

每行记录一个节点与上级，根节点的上级留空。

## 统计图形及应用

使用组织树表达职责归属。

## 视觉编码

纵向位置表示层级，连线表示直接隶属。

## 信息框架

筹备组 → 分组 → 具体职责。

## 叙事框架

从顶层向下阅读，也可沿任务向上找到负责小组。

## 设计观察

如需表现跨组协作，可补充区别于隶属线的连线与图例。
