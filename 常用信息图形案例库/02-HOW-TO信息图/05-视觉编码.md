# HOW-TO 信息图：视觉编码

- 数字：表示步骤顺序。
- 箭头：表示前进方向。
- 图标/插画：表示工具、动作或对象。
- 颜色：区分阶段、警告和完成状态。
- 形状：菱形常用于判断，矩形常用于操作步骤。
- 文字：每步尽量使用简短、明确的动词句。

## 案例｜如何制作作品展签

序号与纵向位置共同表达先后，交替使用深浅色辅助辨认行。

## 案例｜《Chess rules》国际象棋规则

| 分析角度 | 版面表现 | 对应信息与阅读作用 |
|---|---|---|
| 颜色与动作 | 绿箭头表示移动，黄箭头表示吃子，蓝箭头表示可移动也可吃子的路径。 | 颜色区分动作，可结合图例对照兵的直走和斜吃。 |
| 方向与格数 | 棋盘格上可见直线、斜线、邻格和马的折转箭头。 | 格子提供位移参照，箭头指示方向和可达位置，移动限制由旁文补充。 |
| 编号与顺序 | 两种特殊走法使用红色编号，后翼弃兵使用蓝色编号。 | 编号表示各自示例的动作顺序，基本走法上的多支箭头则表示可选方向。 |
| 形状与对应 | 不同棋子用不同剪影表示，临近棋盘上摆出相应棋子。 | 形状帮助识别棋子，邻近位置对应名称、说明与示意。 |
| 字号与分区 | 主标题位于红黑棋盘格区，白底集中规则，深色带承载大数值，底部用双肖像展示对阵。 | 标题支持版块定位，字号强调指标，数值由数字及单位直接读取。 |

## 案例｜《BLACK TEA》红茶冲泡与制茶流程

| 分析角度 | 版面表现 | 对应信息与阅读作用 |
|---|---|---|
| 编号与路径 | 红色圆形编号标出 01–04，粗金色折线连接冲泡场景。 | 编号确定先后，实线引导视线跨区域移动。 |
| 线型与注释 | 主流程使用粗实线，局部说明使用细点线和端点。 | 实线引导阅读主流程，点线定位温度、称量等补充说明。 |
| 尺度与焦点 | 中央茶壶与右下成品茶杯放大，茶具名录采用相近的小图标。 | 大图强调关键操作及完成结果，小图标便于逐项查阅。 |
| 动作与图像 | 水壶倾斜并流出水，量勺、茶滤和保温罩出现在相关场景。 | 器具姿态帮助读者将文字步骤对应到具体动作。 |
| 数字与单位 | 90–95°C 与 3 g、300 ml、3 min 单独突出。 | 数字与单位提供操作参照，集中标记便于核对投茶量、水量和浸泡时间。 |
