# 视觉编码

| 分析角度 | 画面表现 | 对应信息与阅读作用 |
|---|---|---|
| 沿弧位置与日期 | 周日期沿同一弧带依次排列。 | 可用日期定位和比较邻近周段。其他环带是否共享刻度待核实。 |
| 径向位置与分层 | 点阵、菱形、日期气泡和曲线分布于不同环带。 | 径向位置区分图层，各层独立尺度需查阅完整图。 |
| 形状与纹理 | 圆点、黑色菱形、斜线纹理和曲线并置。 | 可借形状定位图层，再与图例中的 `black diamond`、`hatched arcs` 等条目核对。 |
| 大小与透明度 | 圆点与气泡尺寸、透明度有变化，局部标记叠加。 | 叠加也会加深颜色，观察深浅时需区分单个标记的透明度与叠加效果。 |
| 色彩与线条 | 红、黑、灰贯穿各层，外侧曲线有粗细与明暗变化。 | 对比有助于追踪轮廓，密集处有遮叠。颜色和线宽对应的字段待核实。 |

## 案例｜《Bauhaus》包豪斯发展史

| 分析角度 | 画面表现 | 对应信息与阅读作用 |
|---|---|---|
| 角向位置与年份 | 年份沿主环排列，径向辅助线穿过多条轨道。 | 沿弧追踪相邻年份，沿同一条径向线对照同一年附近的记录。 |
| 径向位置与分轨 | 校址、作品、校长和教师分布于不同半径的轨道。 | 半径区分信息组，支持单轨纵览和跨轨对照。 |
| 弧段与节点 | 人物姓名沿连续弧段标注，作品以圆点与标签定位。 | 连续弧段呈现跨年区间，节点定位具体年份，区间长短结合起止年份读取。 |
| 色彩与符号 | 图例用不同颜色与样式的圆形标记区分类别，橙红色也用于标题和作品带。 | 类别依据图例和标记判读，大面积橙红同时用于强调及分区。 |
| 字号与方向 | 大号城市年份和作品带斜向排布，主环文字随弧线转向。 | 大年份便于快速定位，斜带支持按年浏览，环上小字适合放大逐轨读。 |
| 两种圆图的结构 | 主环沿圆周标年份，课程图用内外圈分层、用扇区列课程与材料。 | 主环沿角度组织时间，课程图依靠圈层组织课程结构。 |
