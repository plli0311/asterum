## 二、常用信息图形案例库

当前先按已明确提出的三个例子建立子文件夹：词云图、HOW-TO信息图、文字型信息图。新增类型时，复制已有文件夹结构。

每个类型文件夹统一包含：
1. `01-示例图/`：存放原始示例图片。
2. `02-分析报告.md`：分析定义、用途、特点和案例。
3. `03-数据结构.md`：说明数据字段及 Excel 组织方式。
4. `04-统计图形及应用.md`：说明适合的图表及场景。
5. `05-视觉编码.md`：说明颜色、大小、位置、形状、字体等表达方式。
6. `06-信息框架.md`：说明内容模块如何组织。
7. `07-叙事框架.md`：说明读者如何阅读和理解信息。

## 三、案例命名规则
- 图片：`案例编号-案例名称.png`（也可使用 jpg/webp）。
- 五大分类报告：`案例名称-信息图分析报告.md`。
- 每个案例记录来源；不确定的信息标记“待核实”，不要猜测。

## 四、新增案例的更新步骤
1. 把原图放入对应的 `01-示例图/` 或案例资料位置。
2. 复制模板，建立独立分析报告。
3. 分析数据结构、图形应用、视觉编码、信息框架和叙事框架。
4. 更新对应分类的总文档，记录新案例带来的发现。

## 五、分析原则
先判断信息是**按照什么逻辑组织**，再判断使用了什么图形。一个案例可以同时具有多种类型特征，但要写清楚主要类型和辅助类型。
